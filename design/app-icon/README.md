# 数字解密 · 应用图标

## 设计概念

新版采用实色 2×2 圆角密码瓷砖：左上暖金色「7」，右上米白色「?」，左下淡紫色「3」，右下薄荷绿色对勾。深靛蓝与暗紫背景衬托高对比度的深色符号，以数字、未知答案与解密成功表达猜数字玩法。

相比上一版细描边密码格，实色块更便于桌面小尺寸辨认。图标是游戏主题标识，不表示实际对局会逐位揭示判定。

## 交付文件

| 文件 | 规格与用途 |
| --- | --- |
| `app-icon-1024.png` | 1024×1024 RGB，不透明完整方形版，独立交付原图 |
| `app-icon-rounded-1024.png` | 1024×1024 RGBA，透明边距与圆角版 |
| `app-icon-preview.png` | 48、72、96、128、192px 图标在浅色与深色背景下的预览 |

应用内同步使用同一张 512×512 RGBA 圆角图标：

- `entry/src/main/resources/base/media/icon.png`：桌面入口。
- `AppScope/resources/base/media/app_icon.png`：应用级图标。
- `entry/src/main/resources/base/media/startIcon.png`：启动窗口图标。

保留现有媒体资源名称和引用配置。应用内圆角版沿用原资源约 3.1% 的透明边距，避免改变现有呈现方式。

## 图片处理

生成图片为 1254×1254。图片结果恢复为本地 PNG 并验证可打开后，使用 Pillow 的 Lanczos 重采样导出 1024×1024 原图与 512×512 应用图标；圆角蒙版使用四倍分辨率绘制后降采样。

生图返回没有可用文件路径，不代表生成失败。应检查当前调用返回的图片结果并解码验证，不要反复搜索不存在的文件，也不要仅因空工具响应就重复生成。
