# 推理记录与全屏回顾验证

日期：2026-10-28

## 实现范围

- 正式对局采用共享的紧凑历史行：次数、按位排列的猜测数字、正位数量、错位数量。保留两种反馈的文字表头、0 数量和读屏描述，不揭示具体哪一位正确。
- 手机记录区优先占用剩余空间；当前输入移到键盘上方，减少顶部留白，数字键保持 52vp 高。输入区在可用高度不足时可以独立滚动。
- 600vp 及以上的可用宽度采用历史／输入双栏；窄屏五位或较大字体下，历史反馈自动改为两行。尺寸预算不是实机验收结论。
- 记录标题显示总条数，提供全屏回顾、继续输入、按需滚动条、滚动提示和回到最新入口。回顾保留草稿和进入前的列表偏移。
- 进入回顾取消尚未执行的自动提交；返回不自动提交保留的完整输入。回顾不扣机会、不暂停计时。后台或页面隐藏时取消待提交任务。
- 新记录前插时，正在顶部则显示最新；正在查看旧记录则补偿一条记录的高度，保留回看位置。
- 胜负结算均可查看本局记录；退出回顾返回结果，不重置已结束状态、不重复保存成绩。结果卡限制安全区内高度，内容可滚动。
- 教学练习移除最近三条截取，使用有界滚动列表展示全部本局记录，避免无限练习记录将键盘持续推远。
- 保留玩法、自动提交延迟、原有键盘排列、提示和 AI 扣次规则。没有安装到手机、清除数据、修改签名或提交 Git。
