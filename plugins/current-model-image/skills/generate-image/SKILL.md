# 当前模型生图

使用本插件的 MCP 工具完成生图，不临时写 Python、curl 或脚本，不自行读取密钥，不搜索历史会话或日志中的图片。

## 模型与连接

1. 从当前任务的可信会话环境确认模型名。将完整 `providerId/modelId` 中的 **modelId** 传给工具的 `model`。本地初始配置为供应商 NS-GPT，已验证模型为 `gpt-6.1-sol`。
2. 不把 `gpt-6.1-sol` 硬当成所有任务的当前模型。不能确定当前模型时让用户明确模型；不要猜测、切换供应商或悄悄改用 `gpt-image-*`。
3. 初次使用或更换模型时调用本插件的 `check_connection`，传入当前模型名。该调用不生图，只检查配置、连接和模型列表；列表存在不等于模型保证支持图像工具，生成结果才是最终依据。
4. 本插件从已存在的本地 ZCode 个人供应商配置读取 API 地址和密钥。MCP 工具不能感知模型下拉框：模型由你显式传入，供应商在本地配置里选择；供应商不匹配就报告，绝不跨供应商回退。

## 生成

调用本插件的 `generate_image`：

- `prompt`：完整的画面需求、主体、风格、构图、背景、配色和避免项。生图提示词会发送到已配置的供应商，不擅自附带源码、密钥、隐私或用户未请求上传的文件。
- `model`：当前会话的准确模型 ID。
- `output_path`：本机绝对 `.png` 文件路径。优先使用当前工作区的 `generated-images/` 或用户指定目录，文件名有意义。不要覆盖现有文件；新设计或变体用新文件名。
- `width` / `height`：最终导出像素，默认均为 1024，取值 256–2048。API 原图可能是 1254×1254 等尺寸，插件在本地缩放到精确尺寸；目标和原图宽高比不同时会中心裁切，不能裁掉主体，提示词中预留安全区。
- `quality`：默认 `auto`，仅用户明确需要时调整。

一次调用只做一次生图请求。不要为了可视化预览再次生图；不要对超时、断网、空显示自动重试，它们可能已经计费。失败先读取工具返回原因。`reused: true` 表示该路径已有可用 PNG，被直接复用，**不是本次提示词的新生成结果**；若用户明确要新图，改用新的输出路径再调用。

## 检查与交付

工具成功返回 `path`、`width`、`height`、`source_width`、`source_height`、`model` 和 `reused`。只有工具确认 PNG 可解析且已保存后才能宣布完成。

用 Read 打开返回 PNG 查看（仅必要验证），并在最终回复中用真实绝对路径预览：

```markdown
![生成图片](C:/真实目录/真实图片.png)
```

同时提供图片链接，说明实际尺寸。不要只回复“已生成”或粘贴 Base64。如果工具成功但预览未显示，仍可交付返回路径，不要重发生成请求。

## 边界

该版本只生成图片，不接收参考图、不编辑已有图、不自动替换项目资源。用户要接入应用时，在生图后另行检查项目资源并按明确需求替换。仅换图标不应顺便修改业务代码。

工具缺失意味着插件尚未安装、未启用或当前任务工具目录未刷新；引导用户在设置中检查插件并新开任务，不要退回读取供应商密钥或扫描日志。
